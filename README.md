# 🥁 Drum Game


<img width="1305" height="589" alt="image" src="https://github.com/user-attachments/assets/760f93db-b780-4f18-9df6-fac493dd6fb5" />


**Drum Game** is a fun and interactive web-based application that lets you play virtual drums using your keyboard or mouse clicks. Built with simple HTML, CSS, and JavaScript, it’s a great way to practice event handling, audio playback, and DOM manipulation.

---

## 🚀 Features

- Press keys (e.g. `w, a, s, d, j, k, l`) to play different drum sounds  
- Click on on-screen drum buttons to play sounds  
- Simple and responsive design  
- Audio feedback + button animation when a drum pad is triggered  
- Lightweight — works on both desktop and mobile browsers

---

## 🛠️ Built With

- **HTML** for markup  
- **CSS** for styling (you can use Tailwind or regular CSS)  
- **JavaScript** for logic and event handling  
- **Audio** files to simulate drum sounds
